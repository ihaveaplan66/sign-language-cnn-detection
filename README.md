# Sign Language Detection with CNN

This project focuses on building a Convolutional Neural Network (CNN) to classify hand gestures. The project includes data preprocessing, model training and evaluation. The model is trained on a dataset consisting of images of hand gestures.

## Dataset
[ASL Alphabet](https://www.kaggle.com/datasets/grassknoted/asl-alphabet)

## Technologies Used
- Python
- TensorFlow (Keras)
- KerasTuner
- NumPy, Matplotlib
